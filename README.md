# 时间规划器

一个网页版的周 / 日 / 列表时间规划工具。双击用浏览器打开即可使用，不用安装、不用联网、没有账号。

---

## 三分钟上手

1. **拖空白新建**：在网格空白处按住往下拖一段，松手弹出任务框，写标题、点「完成」。
2. **改时间**：按住任务块拖动；拖块的上下边缘改时长；横向拖到别的日期列，就换到那天。
3. **勾完成**：点任务块右上角的圆圈，对勾画出来、删除线划过去，块褪成浅色。
4. **先记下来再排**：右侧「＋ 记一件待排的事」，把想法丢进待办池，之后再拖进网格。
5. **看列表**：顶栏「日 / 周」右边那个按钮，把一周摊成七列清单，任务变成一个个小色块。

---

## 视图与导航

| 操作 | 效果 |
| --- | --- |
| 「日 / 周」 | 切换视图，附带列宽变形动画 |
| 「日 / 周」右边的图标 | 时间块 ⇄ 列表，图标跟着当前视图换 |
| 「今天」 | 回到今天所在的那一周 / 那一天 |
| `‹` `›` | 上一周 / 下一周（日视图下是前一天 / 后一天） |
| 日视图日期下的小字 | 非今天时标出「明天 / 后天 / 5 天后」 |
| 时间轴上的黑色小幽灵 | 当前时刻的位置 |

列表视图是另一套排法：七个日期并排，每天下面一条条往下排，任务只占一个按字数收放的小色块（颜色跟分类走），行与行之间一条细横线，一屏下来像一张有格的周清单。**行高就是时间块视图的每小时高度**，两个视图的纵向节奏一致。它不按时间定位、也不显示时间——想知道几点，回时间块视图看。

列表里能做的事和别处一样全：点色块打开编辑弹窗；点空行在那天加一条；鼠标移到某行右侧浮出完成圈；**按住色块上下拖就是换顺序、左右拖就是换到那一天**（落点画一条黑线，松手生效；列表里的顺序即时间顺序，拖到谁的下面，时间就接在谁后面）；**待办池里的条目也能直接拖进来**，落在哪一天哪两条之间，就插在那里。列窄的时候星期会先撤掉，日期保证留在列内。

左上角只写一个月份：取这一屏里日期最多的那个月，所以跨月的那一周不会再出现「10月—11月」。

## 任务

点开任务块的弹窗有这些字段：

- **标题**（占位「做点什么」）
- **日期** + **起止时间**
- **分类** —— 默认五类：课程（蓝）、自习（绿）、锻炼（橙）、生活（粉）、其他（紫）
- **重复** —— 不重复 / 每天 / 每周
- **备注**（占位「描述一下」）
- 底部「删除」和「完成」

分类可以改名换色：弹窗里点「修改」，或者进设置面板的「分类名称与颜色」，每行都能改名字、点色块换颜色。「恢复默认」一键还原。

同一时刻有两个任务时，列会自动切成并排的几条泳道，时间拆成上下两行写，起止都写全。

> 重复任务拖到别的日期时，会拆成一条独立的任务，不影响原来那串。

## 待办池

- 「＋ 记一件待排的事」→ 浮出输入框。`Enter` 添加，`Shift + Enter` 换行，`Esc` 取消。
- **点一下条目就能改文字**：回车或点别处保存，`Esc` 放弃；清空再保存等于删掉这条。
- 池里的条目是白色圆角块，**按住拖进网格**就变成任务，落点决定开始时间，拖到哪一列就是哪一天；**拖进列表视图**也一样，落在哪两条之间就插在那里。
- 池子左边缘可以左右拖动调整宽度，主视图会跟着按比例让位。
- 底部常显统计：本周 / 这天的总时长，以及各分类的时长占比条。

## 导出

点右上角「导出」：

| 选项          | 说明                             |
| ----------- | ------------------------------ |
| 图片 · 手机竖版   | PNG，适合发群里或存相册                  |
| 图片 · A4 日程表 | PNG，A4 比例，适合打印                 |
| 打印 / 存为 PDF | 走浏览器打印。周视图和列表横向 A4 一页，日视图纵向 A4 一页 |
| 导出数据备份      | 下载 `时间规划备份-YYYY-MM-DD.json`    |
| 导入数据备份      | 选一个之前导出的 `.json`，覆盖当前任务和待办池    |

打印时建议在打印对话框里关掉「页眉和页脚」，纸面会干净很多。

## 设置

点顶栏齿轮进入设置，分五组：

**时间轴**

- 显示范围：起点 / 终点整点，默认 06:00 — 24:00（最短跨度 2 小时）
- 每小时高度：紧凑 44px / 标准 56px / 宽松 72px

**排程**

- 时间步长：5 / 10 / 15 / 30 分钟，拖拽时吸附到这个粒度
- 每周起始：周一 / 周日

**新建任务**

- 默认分类：新建时预选哪一个
- 默认时长：30 分 / 1 时 / 1.5 时 / 2 时

**分类名称与颜色**

- 五类逐行改名、换色，右上角「恢复默认」

**数据**

- 恢复默认设置：只把设置项还原成出厂值，不动任务
- 清空全部数据：清掉所有任务和待办池。要点两次（按钮会变成「确定清空」，4 秒内不点就自动取消），**不可撤销**；设置项和分类颜色会保留

## 快捷键

| 按键        | 作用                          |
| --------- | --------------------------- |
| `←` / `→` | 上一周 / 下一周（日视图为前一天 / 后一天）    |
| `T`       | 回到今天                        |
| `N`       | 在当前选中日期的 09:00 新建一条任务       |
| `Esc`     | 逐层关闭：设置 → 任务弹窗 → 池输入 → 导出菜单 |
| `Enter`   | 在任务弹窗的标题框里保存                |
